# ``FoundationFramework``

Access essential data types, collections, and operating-system services to define the base layer of functionality for your app.

## Overview

The ``FoundationFramework`` provides a base layer of functionality for apps and frameworks, including data storage and persistence, text processing, date and time calculations, sorting and filtering,
and networking. The classes, protocols, and data types defined by ``FoundationFramework`` are used throughout the various SDKs.
